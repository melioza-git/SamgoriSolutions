Why now

SuiteScript 2.1 becomes required for every custom script.

Accounts implemented years ago often carry legacy scripts that nobody has reviewed, and many are still enabled but no longer used. A plan now costs far less than a scramble later.

NetSuite 2027.1

SuiteScript 1.0 enters end-of-life support

Support narrows to critical issues only.

NetSuite 2028.1

2.0 and 2.x scripts run as 2.1 by default

Whether or not the code has been reviewed for the newer runtime.

NetSuite 2028.2

Every script must use SuiteScript 2.1

Legacy versions and annotations are removed.

Dates follow Oracle's published transition guidance, which can change between releases. See Oracle's Transitioning to SuiteScript 2.1 and confirm against your release notes.
